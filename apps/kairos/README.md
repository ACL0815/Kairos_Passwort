# kairos

GUI-Binary und Verdrahtung aller Komponenten. Vorgesehen ist egui/eframe (PR-3)
mit Profilwahl 0–12, Neugenerierung, manueller Nachbearbeitung, farbigen Segmenten,
eingebetteter Passwort-Schriftart sowie Kopieren / Kopieren und Zurückspringen.
Das Scaffold besitzt nur einen ausführbaren Status-Einstieg.

Die Gestaltung folgt verbindlich [UI-STYLE.md](../../docs/design/UI-STYLE.md).
Das lokale Stock-Referenzbild wird nicht mitgeliefert. Schriftdateien dürfen
erst mit dokumentierter, redistributionsfähiger Lizenz aufgenommen werden.

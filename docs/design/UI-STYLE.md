# Stilvorgabe für Kairos Passwort

## Visuelle Richtung

Dunkles Navy-Dashboard mit ruhigen Glas-Panels und dünnen hellblauen Rahmen.
Der Grundhintergrund liegt ungefähr bei `#0A1030`; Panels dürfen leicht heller
und transparent wirken. Ein Ring als zentrales visuelles Motiv verwendet einen
Neon-Verlauf **Violett → Pink → Orange**. Cyan-/Blau-Akzente strukturieren
Bedienelemente, Magenta setzt Highlights, Bernstein/Gelb hebt Zahlen hervor.

| Rolle | Richtwert |
|---|---|
| Hintergrund | Navy `#0A1030` |
| Panel | Dunkles Blau, etwa `#111C3C`, mit zurückhaltendem Glaseffekt |
| Panel-Rahmen | Dünnes Hellblau, etwa `#78BFFF`, geringe Deckkraft |
| Ring | Violett `#8B5CF6` → Pink `#EC4899` → Orange `#FB923C` |
| Interaktion | Cyan `#22D3EE`, Blau `#3B82F6` |
| Sonderzeichen / Highlights | Magenta `#F472D0` |
| Ziffern | Bernstein `#FBBF24` bis Gelb `#FDE047` |
| Haupttext | Helles Blauweiß, etwa `#EAF2FF` |

## Bedienung

Das Passwort steht im Mittelpunkt. Profilwahl 0–12, Entropie, Neu generieren,
manuelles Bearbeiten, Kopieren und Kopieren + Zurückspringen müssen klar
erkennbar sein. Die Farbzuordnung nutzt die Segmente des Core-Vertrags.
Großschreibung erhält zusätzlich ein unterscheidbares Highlight. Lesbarkeit,
sichtbarer Tastaturfokus und klare Zustände gehen vor dekorativem Leuchten.

Eine eingebettete Passwort-Schriftart soll `0/O`, `1/l/I` und Sonderzeichen
eindeutig unterscheiden. Ihre Redistributionslizenz und Herkunft sind vor der
Aufnahme zu dokumentieren. Echte Passwörter gehören nicht in Screenshots oder Logs.

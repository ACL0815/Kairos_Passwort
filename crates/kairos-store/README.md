# kairos-store

Import externer Wortlisten in eine SQLCipher-Datenbank mit Sprach-Flag,
randomisierter Speicherung und Schlüsselabsicherung über Windows DPAPI (PR-5).
Die Wortquelle implementiert `kairos_core::WordSource`; im Scaffold sind weder
Datenbank noch Schlüsselverwaltung implementiert.

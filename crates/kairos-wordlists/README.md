# kairos-wordlists

In die EXE eingebettete Wortlisten, zuerst Deutsch (PR-2), später Englisch und
Latein (PR-7). Die Implementierung stellt `kairos_core::WordSource` bereit.
Dieses Scaffold enthält noch keine Wortdaten. Auswahl, Normalisierung,
Filterpipeline, Duplikatfreiheit und Datenlizenz werden vor dem Einbetten dokumentiert.

## Open-Source-Vorbilder (modellieren, nicht kopieren)

Platzhalter für PR-2: [wordlists.md](../../docs/sources/wordlists.md).
Die spätere Spracherweiterung besitzt [languages.md](../../docs/sources/languages.md).

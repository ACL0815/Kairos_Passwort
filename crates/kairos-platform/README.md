# kairos-platform

Windows-Dienste für globale Hotkeys, Autotype, Fokus-Rücksprung und Zwischenablage
mit Timeout sowie Verlauf-/Cloud-Ausschluss (PR-4). Die Crate bleibt unabhängig
vom Core; die Anwendung reicht Geheimnisse nur für die benötigte Dauer weiter.
Das Scaffold führt noch keine Betriebssystemaktionen aus.
